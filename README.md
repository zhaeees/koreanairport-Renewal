## 📌 Project Overview

기존 사이트는 정보 중복과 복잡한 구조로 인해 <br/>
사용자가 핵심 콘텐츠에 빠르게 접근하기 어려운 문제가 있었습니다.

또한 반응형 설계와 접근성 측면에서도 한계가 존재하여 <br/>
사용자 중심의 정보 재구성과 UX 개선을 목표로 리뉴얼을 진행했습니다.

### 🔍 Why Renewal?
1. 복잡한 정보 구조
   - 중복된 정보 배치
   - 콘텐츠 위계 구조 불명확
   - 사용자의 판단 피로도 증가

2. 탐색 동선 문제
   - 핵심 기능까지 도달하는 단계가 많음
   - 목적별 페이지 분리가 명확하지 않음

3. 반응형 · 접근성 한계
   - 모바일 환경 최적화 부족
   - 시각적 정보 전달 중심 구조

4. 브랜드 신뢰도 저하
   - 디자인 최신성 부족
   - 정보 업데이트 체감도 낮음
     


## 🎯 Renewal Goals
본 리뉴얼은 **정보 구조 단순화 + 사용자 동선 개선**을 통해 <br/>
핵심 콘텐츠 접근성을 높이는 것을 목표로 합니다.

* 정보 탐색 시간 단축
* 콘텐츠 우선순위 재정의
* 반응형·접근성 강화


## 🛠 Improvement Strategy
🔹 사용자 목적 기반 구조 분리

- 채용 페이지 → 행동 유도 중심 구조
  - CTA 강조
  - 핵심 정보 상단 배치
  - 지원 프로세스 단순화

- 공항 이용 페이지 → 정보 탐색 중심 구조
  - 빠른 정보 확인 가능
  - 시각적 안내 강화
  - 단계적 정보 구조 설계

👉 사용자가 불필요한 판단 과정을 거치지 않고
각 페이지의 목적을 즉각적으로 인지할 수 있도록 설계했습니다.


## 🚀 Key Features (Before → After)

1️⃣ 실시간 날씨 API 연동
  - Weather API를 통해 실시간 날씨 데이터 자동 수신
  - 수신한 날씨 코드값 기반 조건 분기 처리
  - 날씨 상태에 따라 아이콘 자동 변경
    
✔ 데이터 기반 UI 제어 방식으로 사용자 체감 정확도 향상<br/>
✔ 실시간 정보 반영으로 브랜드 신뢰도 개선


2️⃣ 데이터 구조 개선  
   - 배열 기반 데이터 구조 설계
   - 위치 좌표 및 ID 자동 생성 방식 적용
   - 유지보수성과 확장성 고려한 구조 설계

✔ 하드코딩 제거 <br/>
✔ 기능 확장 시 최소 수정 구조 확보  


3️⃣ Swiper 인터랙션 강화
   - Swiper 슬라이더에 rotate 반응형 효과 적용
   - 모바일 환경에서 몰입감 있는 인터랙션 제공  

✔ 정적인 슬라이드 → 공간감 있는 UI 경험


4️⃣ 공항 소요시간 시뮬레이션 UI
   -가상 데이터 기반 이동 시간 계산
   - 사람 이동 애니메이션으로 소요 시간 시각화
   - 수치 중심 정보 → 직관적 인터랙션 UI로 전환

✔ 시간값에 따라 animation-duration 동적 조절 <br/>
✔ 정보 전달력 + 재미 요소 동시 강화
  

## 💡 UX Improvement Point
| Before       | After         |
| ------------ | ------------- |
| 텍스트 중심 정보 제공 | 인터랙션 중심 정보 전달 |

| 수동 정보 확인     | 데이터 기반 자동 반영  |
